# Управление студкружками (StudentsClubManager)

## Назначение приложения
Приложение предназначено для управления студенческими кружками: просмотра информации, записи участников, ведения расписания и контроля посещаемости.

## Основные экраны
1. **Главная страница (Каталог кружков)**: Список всех доступных кружков с кратким описанием.
2. **Карточка кружка**: Детальная информация о кружке, преподавателе, список участников и кнопка "Записаться".
3. **Расписание**: Календарь или список предстоящих занятий для выбранных кружков.
4. **Журнал посещений**: Экран для старосты или преподавателя, позволяющий отмечать присутствующих на конкретном занятии.

## Пользовательские сценарии
* **Студент**: просматривает список кружков, открывает карточку интересующего, нажимает "Записаться", просматривает свое расписание.
* **Преподаватель/Администратор**: открывает журнал конкретного занятия и проставляет отметки о присутствии участников.

## Инструкция по запуску
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите локальный сервер для разработки:
   ```bash
   npm run dev
   ```
3. Откройте в браузере ссылку http://localhost:5173

## Модель данных (Backend)
- **Club (Кружки)**: id, name, teacher, description. Связан с расписанием (One-to-Many).
- **Student (Студенты)**: id, full_name, group_name.
- **Timetable (Расписание)**: id, club_id (FK), date, time, room.

## Инструкция по запуску Backend
1. Установите зависимости: `pip install -r backend/requirements.txt`
2. Создайте базу данных PostgreSQL и укажите путь к ней в файле `backend/.env`.
3. Запустите сервер: 
   ```bash
   cd backend
   uvicorn main:app --reload
   ```
Документация API доступна по адресу: http://127.0.0.1:8000/docs

## Аутентификация и авторизация
- **Хранение паролей**: Пароли хешируются с помощью алгоритма `bcrypt` с генерацией соли.
- **Токены**: При входе (`/auth/login`) выдаются JWT `access_token` (срок действия 15 минут) и `refresh_token` (срок действия 7 дней, сохраняется в таблице `refresh_tokens`).
- **Обновление и выход**: Маршрут `/auth/refresh` выдаёт новый `access_token` по действующему и неотозванному `refresh_token`. Маршрут `/auth/logout` отзывает `refresh_token` текущей сессии (`is_revoked = true`).
- **Разграничение прав**: Публичные маршруты доступны всем (просмотр кружков и расписания), запись в кружки доступна авторизованным пользователям (`student`), а управление кружками и редактирование журнала посещаемости — только роли `teacher`.

## Интеграция Frontend и Backend (ЛР5 — Итоговый MVP)
- **Реальные данные из PostgreSQL**: Все экраны (`ClubsList`, `ClubDetails`, `Timetable`, `Attendance`) подключены к REST API на FastAPI через единый клиентский модуль `src/shared/api/clubs.ts`. При первом запуске бэкенд автоматически инициализирует стартовый набор кружков, студентов и расписания в PostgreSQL.
- **Полный цикл CRUD и ролевой доступ**:
  - Гости могут просматривать каталог кружков, состав участников и расписание занятий.
  - Авторизованные пользователи (`student`, `teacher`) могут подавать заявки на вступление в кружки (`POST /students/` и `POST /clubs/{id}/enrollments`) и просматривать журнал посещаемости.
  - Преподаватели (`teacher`) могут создавать, редактировать и удалять кружки (`POST/PUT/DELETE /clubs/`), управлять расписанием (`POST/PUT/DELETE /timetables/`), отчислять студентов из кружка (`DELETE /clubs/{id}/enrollments/{student_id}`) и сохранять отметки посещаемости в БД (`PUT /timetables/{id}/attendance`).
