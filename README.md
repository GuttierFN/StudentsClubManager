# Управление студкружками (StudentsClubManager)

## Назначение приложения
Приложение предназначено для управления студенческими кружками: просмотра информации, записи участников, ведения расписания и контроля посещаемости.

## Основные экраны
1. **Главная страница (Каталог кружков)**: Список всех доступных кружков с кратким описанием.
2. **Карточка кружка**: Детальная информация о кружке, преподавателе, список участников и кнопка "Записаться".
3. **Расписание**: Календарь или список предстоящих занятий для выбранных кружков.
4. **Журнал посещений**: Экран для старосты или преподавателя, позволяющий отмечать присутствующих на конкретном занятии.

## Пользовательские сценарии
* **Студент**: просматривает список кружков, открывает карточку интересующего, нажимает "Записаться", просматривает свое расписание.
* **Преподаватель/Администратор**: открывает журнал конкретного занятия и проставляет отметки о присутствии участников.

## Инструкция по запуску
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите локальный сервер для разработки:
   ```bash
   npm run dev
   ```
3. Откройте в браузере ссылку http://localhost:5173
